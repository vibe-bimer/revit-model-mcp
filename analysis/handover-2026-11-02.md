<a id="what-this-repository-is"></a>
## 这个仓库是什么

`vibe-bimer/revit-model-mcp` 是 `sharafutdinovdi/revit-model-mcp`（下称「底座」）的 fork。底座的 Release 1.0 已经把 79 个工具做完了，本仓库在它之上加一层自己的东西。

这层东西分两类：

| 类别 | 含义 | 现状 |
| --- | --- | --- |
| 底座工具 | 底座自带的读取与动作工具 | 79 个，全部可用 |
| fork 工具 | 本仓库自己写的动作工具 | 11 个，1 个已接、10 个待移植 |

「已接」指工具在 `integration/upstream-1.0` 分支上能列出并执行；「待移植」指实现已经在 `main` 上，但那个分支还没有对应命令。状态表在 `docs/platform/fork-tools.md`，由生成器维护，不要手改。

fork 层的代码只允许落在 `build/fork.json` 列出的路径里：`src/RevitModelMcp.Core/Fork/`、`src/RevitModelMcp.Addin/Fork/`、`server/revit_model_mcp/fork_actions.py`、`docs/`、`tools/site/` 等。底座自己的 `ActionMutations.cs` 不在其中，改它会让 `build/check_fork_budget.py` 判失败。

<a id="the-daily-loop"></a>
## 每天的循环

```powershell
# 1. 关 Revit（先确认模型没有未保存改动）
Stop-Process -Name Revit -Force

# 2. 构建 + 部署（DeployAddin 默认 true，一条命令到位）
cd $env:USERPROFILE\revit-model-mcp
dotnet build src/RevitModelMcp.Addin/RevitModelMcp.Addin.csproj -c Debug.R26 -p:LaunchRevit=false

# 3. 签名
powershell.exe -NoProfile -ExecutionPolicy Bypass -File $env:USERPROFILE\sign-addin.ps1

# 4. 起 Revit（SSH 在 session 0，直接 Start-Process 起不来，必须走计划任务）
schtasks /Run /TN RevitMcpLaunchVerify

# 5. 本地通道调用
cd server
$env:REVIT_MCP_HOST = 'local'
uv run python -m revit_model_mcp.server
```

细节、坑和调试方法见[工作站开发](workstation-dev.md)。

<a id="gates-and-gotchas"></a>
## 门禁与坑

提交前跑：

```powershell
dotnet test --project tests/RevitModelMcp.Core.Tests/RevitModelMcp.Core.Tests.csproj
cd server; uv run --with pytest pytest -q
cd ..; uvx ruff==0.16.10 check .; uvx ruff==0.16.10 format --check .
pre-commit run --all-files
python build/check_fork_budget.py
python tools/site/generate_features.py --check
```

几个容易踩的：

- **C# 格式化钩子在 Windows 上会真的改文件**（非 Windows 上只打印提示并跳过），第一次跑先看 diff；
- **`generate_features.py --dump` 必须在 `server/` 下带 pyyaml 跑**，否则 `ModuleNotFoundError: No module named 'yaml'`；`--write` 之前必须先 `--dump`；
- **含中文的 `.ps1` 必须 UTF-8 with BOM**，否则 PowerShell 按 GBK 解析报「字符串缺少终止符」；
- **关 Revit 用 `Stop-Process -Force`**，`CloseMainWindow()` 会被保存提示挡住；前提是模型本来就没保存过；
- **动作永远不保存模型**。验收的最后一条永远是「写入后文件大小与 mtime 不变」。
