# 重建性能与成本

测量使用 Revit 2020 和 `建筑结构.rvt` 中 899 个可选构件。

!!! note "记录范围"
    本页是对某次重建会话的摘要：会话的完整记录、日志和原始测量文件不在本仓库内，也无法从这里复现，因此下面只保留当时记录的数值，不补造新的测量证据。数值按记录原样保留。

<a id="what-one-copy-costs"></a>
## 一份副本的成本

| 阶段 | 每份耗时 | 说明 |
| --- | ---: | --- |
| 跨文档粘贴 | ≈14 s | Revit 处理 899 个构件的固有成本（每个 ≈15 ms） |
| 保存 | ≈2.2 s | 保留一份备份 |
| 副本之间的清理 | ≈2 s | 删除上一份副本，让下一份进入新的 ID 区间 |
| **合计** | **≈18–19 s** | 单任务十份：165 s；三十份：约 8–9 分钟 |

<a id="how-it-got-there"></a>
## 优化过程

| 轮次 | 变更 | 十份耗时 | 每份耗时 |
| --- | --- | ---: | ---: |
| 起点 | 每份都粘贴两次（重试检查在映射生成前执行） | 286 s | 28.6 s |
| ① | 重复复制前先检查映射 | 286 s | 28.6 s |
| ② | 保留已粘贴类型，只写一份备份 | 266 s | 26.6 s |
| ③ | 先重试被拒绝的复制，只将逐构件隔离作为最后手段 | **185 s** | **18.5 s** |

<a id="parallelism"></a>
## 并行

多个实例可以并行运行：各自从 `REVIT_MCP_HTTP_PORT`、`REVIT_MCP_TOKEN` 和 `REVIT_MCP_CHANNEL_DIR` 获取端口、令牌与通道目录，并打开各自独立的模型副本，以免 Revit 提示文件已打开。
只有允许 ID 区间重叠时，并行才划算：为每个实例预留号段需要以每个 ID 约 3 ms 的成本消耗 ID；测量结果比串行批次更慢（三个实例、21 份副本：超过 25 分钟，其中第三批单独用了 10.7 分钟）。
无人值守并行还需要处理模态提示：实例同时打开同名模型会触发“文件已打开”等对话框，应在每个实例启动前设置 `REVIT_MCP_ANSWER_DIALOGS=1`，见[自动应答对话框](actions.md#answer-dialogs)。
