# 安全模型

!!! note "中文版"
    本页为中文精简版；把右上角语言切到 English 可看完整英文原文。

- **默认只读**：只有显式打开两道门禁才可能改模型。
- **回环优先**：HTTP 通道默认只监听 `127.0.0.1`；要跨机使用推荐 SSH 端口转发，而不是把端口暴露到局域网。
- **令牌鉴权**：HTTP 请求必须带 `Authorization: Bearer <token>`；令牌首次启动时随机生成，写在 `settings.json`（仅当前用户可读写），可用 `REVIT_MCP_TOKEN` 覆盖。
- **文件权限**：`settings.json` 与 `allow-write` 都做了 ACL 限制（仅当前用户）。
- **路径脱敏**：默认对模型路径做脱敏，需要完整路径时显式设 `REVIT_MCP_REDACT_PATHS=0`。
- **不写入凭据**：日志与结果里不记录令牌、不记录完整模型数据；导出文件写到本地已知目录。
- **动作前置校验**：动作类工具要求"恰好一个 Revit 实例"，避免请求落到错误的模型上。
