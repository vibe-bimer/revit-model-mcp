<a id="known-gaps"></a>
## 已知缺口

- **公开源码清理**：旧版快照读取器、契约和测试夹具仍包含特定组织的族与参数标识符；删除这些字段会改变旧版数据流契约。
- **英文诊断信息**：Capture、Core、视图会话和测试仍包含俄文消息或测试夹具；翻译本地化模型参数别名时，必须保留其查找行为。
- **Python 命名**：`ReadJob` 和 `RevitReadChannel` 同时承载动作，而 MCP 显示名仍写作 Reader；重命名时需要明确的兼容策略。
- **文件协议**：任务缺少关联 ID 和进程间响应归属机制；每个通道目录只使用一个服务器进程。
- **文件响应**：写入不是原子的，轮询客户端可能观察到不完整 JSON；原子发布需要传输回归测试覆盖。
- **采集诊断**：`model-health` 报告 `skipped`，`links-status` 报告每个链接的 `error`；其他尽力而为的读取器仍会吞掉部分参数和几何读取失败，既不报告被跳过字段，也不记录原因。
- **Revit 资源**：读取器和旧版快照路径仍需在真机 Revit 下审计收集器／过滤器的释放。
- **HTTP 关闭**：监听器任务处于脱离管理状态，取消源未释放；释放共享状态前应等待正在处理的请求完成。
- **HTTP 产物**：从未被取回的导出文件没有登记到图像清理机制；结果过期也可能与图像下载发生竞态。
- **HTTP 容量**：已完成响应的存储按时间过期，但没有字节数／条数预算，请求正文也没有读取截止时间。
- **动作策略**：已有 `dry_run` 和 `verification`；尚无确认令牌或无人值守执行策略。
- **参数编辑**：重复参数名和隐式类型回退需要明确的消歧机制，才能扩展动作 API。
- **依赖可复现性**：浮动 NuGet 和 Python 版本范围可能改变依赖还原结果；承诺二进制可复现前，应固定已解析的依赖图。
- **兼容性**：2026-09-12 这一轮验证中，Revit 2022–2025 或 2027 没有真机读取／动作验证；CI 编译不能验证 HTTP ACL 行为或真机执行。
- **发布**：v0.1.0 提供 GitHub 发布资产；MCP Registry 和 PyPI 发布尚不可用。
- **批处理撤销**：Revit 撤销菜单标签（`revit_batch`）无法通过 API 验证。
- **安装**：如果后续年份安装失败，`install.ps1` 没有跨年份回滚机制。
