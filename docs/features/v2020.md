已实测表示记录过真机执行；仅构建表示通过编译，不代表已完成真机功能验证。Revit 2021 不在本项目构建范围。

## 年份差异 {#year-differences}

- 建楼板走 `Document.Create.NewFloor`（`Floor.Create` 从 2022 才有）
- 阶段赋值的顺序检查在 2020 走兜底（相关 API 只在 2022+ 暴露）
