# Revit 2026 support

Revit 2026 is built, but nothing on this branch has been verified against a running Revit 2026.

## What this branch states

- The release workflow builds the Revit 2026 configuration alongside 2022 to 2025 and 2027.
- Every page reports 2026 as build-only until a workstation verification lands.

## Tools

Every one of the 87 tools is built for Revit 2026.

The [version support matrix](matrix.md) lists every tool.
