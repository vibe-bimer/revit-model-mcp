# Revit 2020 features

<p class="facts"><b>Revit 2020</b>　19 read + 14 action tools, 33 in total</p>

## Differences from other years

- Floors are created through `Document.Create.NewFloor`; `Floor.Create` starts at 2022
- The phase order check falls back on 2020, because its API only appears from 2022
- All 19 read tools and all 14 action tools were run live
