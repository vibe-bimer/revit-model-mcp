# Revit 2020

19 read + 15 action tools, 34 in total

19/19 reads and 15/15 actions validated live; the rest are build-only

Validated live means an execution was recorded on a real workstation. Build only means compilation passed, not live functional validation. Revit 2021 is outside this project's build targets.

## Year-specific differences {#year-differences}

- Floors are created through `Document.Create.NewFloor`; `Floor.Create` starts at 2022
- The phase order check falls back on 2020, because its API only appears from 2022
